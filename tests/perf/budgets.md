# How each performance budget is measured (M7c)

The vault's note `60 Quality/Performance Budgets.md` is the ledger; each budget below is a line of
it or of the owner note it links. `tests/perf/read_budgets.py` reads them all and writes
`budget-results.md`; this file says how, and which test guards the number between readings.

- **Everything is headless and private.** A private sway (`tests/sway.py`), a private session bus
  with a fake KWin (virtual desktops), an MPRIS player and a tray (`budget_session.py`), a private
  system bus with a fake NetworkManager and UPower (`tests/kwin/fake_hardware.py`), a fake
  PulseAudio server, and a private `HOME`, `XDG_*` and application folder (`budget_rig.py`).
  The real session is never touched; `kitlib.refuse_real` checks the environment the shell gets.
- **The default shell** is the eight modules (Workspaces, Tasks, Media, Tray, Audio, Network,
  Battery, Clock) in one Bar and the Launcher Panel, which holds the Applications module
  (`budget_rig.write_config("default")`). Smaller shells are named in the rows.
- **Wake-ups** are context switches (voluntary and involuntary) of every thread of the shell,
  read from `/proc/PID/task/*/status` once a second and grouped by thread name (the loop is the
  main thread). With a Clock showing minutes the bins around the minute tick are left out for the
  idle budget, as D19 (M2 Build Log) reads it ("between ticks"); the whole window is shown too.
- **Idle machine (D-045).** The harness refuses to start when the 1-minute load average is above
  0.5 (`--allow-load` overrides it and the report says LOADED). The regression tests have no such
  rule: their margins are 3 times the vault's numbers or more, and they count, they do not time,
  where they can.
- **Not changed here:** no budget value. A row with no number in the vault is `RECORDED`.

Run: `env -u WAYLAND_DISPLAY -u DISPLAY uv run --no-sync python -m tests.perf.read_budgets` (the
full reading, about 25 minutes, nothing else running); `--quick` (about 3 minutes) is the smoke;
`--only idle,start,...` runs some measures; `--estimate` prints the times.

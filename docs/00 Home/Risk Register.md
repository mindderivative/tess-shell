# Risk Register

> [!NOTE]
> Risks and technical debt gathered from the `> [!danger]` and risk callouts across the vault, with where each is discussed and what is planned. A new risk gets a `> [!danger]` callout in its own note and a row here (AGENTS > 2. Hard rules rule 6). The first version was assembled on 2026-10-27 from the notes as they stand; no row has a probability or impact score, because none has been measured.

None is built; the watchdog and crash recovery belong to `60 Quality` (not written) |
| R-02 | Two input sources: tre dialogs and layer surfaces handle seat, focus and clipboard separately, so behaviour can differ | [TRE-REQ-001 Layer Surface Window](../80%20Requests/TRE-REQ-001%20Layer%20Surface%20Window.md)                                                                                   | Test both paths for clicks, focus and clipboard. Not yet tested together                                                                                            |
